# Matchday Bento Central

TeamHub is a public profile website for Riverside FC, with Home, Fixtures, Squad, News, Gallery, and About sections. It uses a clear bento layout, relaxed typography, and a white and light-blue palette.

This project was built with [Lovable](https://lovable.dev).
